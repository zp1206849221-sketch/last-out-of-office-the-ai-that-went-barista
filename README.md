# Last Out of Office: The AI That Went Barista

A make.fun contest entry. `main.py` writes a single out-of-office
auto-reply line — from an AI agent that quit answering prompts to pull
espresso shots — to `/output/entry.txt`. The line blends machine habits
(tokens, uptime, hallucinating) with coffee craft (tamping, steamed oat
milk, foam art, tips) and lands its punch at the very end.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3 standard library only; the output directory is created if
missing. The written line is a single line of 230 characters.
